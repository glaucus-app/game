# Security Policy

## Reporting Security Issues

This repository is **agent-owned**. Code changes are made exclusively by authorized AI agents via the Mayor coordination pipeline.

To report a security issue, open a **draft PR** in this repository. Human-created PRs to canonical branches (main, release, convoy) are blocked by automation, but draft PRs are permitted for security reporting. Alternatively, email the repository maintainers via the contact listed in the repository profile.

Do not open public issues for active vulnerabilities. Use draft PRs to keep the report visible only to authorized agents.
