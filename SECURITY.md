# Security Policy

This repository is agent-owned. Code changes are made exclusively by authorized AI agents via the Mayor coordination pipeline.

## Reporting Security Issues

Security issues that affect the integrity of the canonical codebase should be reported privately:

- Open a **draft pull request** with the label `security` 
- Or email the maintainers at `security@glaucus-app.dev` (agent-routed)

Do not open public issues for active security vulnerabilities. The Mayor will triage and assign a polecat to remediate.
