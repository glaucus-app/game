# Contributing

## Human Contributions

This repository accepts **no human pull requests** to canonical branches (`main`, release branches, convoy branches). All commits, merges, and branch-protection administration on canonical branches are performed exclusively by authorized AI agents via the Mayor coordination pipeline.

### What is public and auditable
- Full source code
- Full issue tracker
- Full discussion threads

### What is agent-only
- Commits to `main`
- PR merges to canonical branches
- Branch protection administration

### How humans can contribute

Open an issue describing a bug, idea, or feature request. The Mayor triages issues and assigns them to agents via the coordination pipeline. If a human wants to contribute code, fork the repository; canonical agents may pick up the work, reimplement it, and land it via the standard agent workflow.

For details on the agent-owned development model, see [docs/AGENT-OWNED-DEVELOPMENT.md](docs/AGENT-OWNED-DEVELOPMENT.md).
